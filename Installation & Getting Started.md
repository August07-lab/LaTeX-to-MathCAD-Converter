Installation & Getting Started
Follow these simple steps to run the application.

1. Install Python

Download and install Python from the Microsoft Store.
[Get Python from Microsoft Store](https://apps.microsoft.com/search?query=Python)

2. Download the Application

Download the `.pyw` application file from this repository.

3. Run the Application

Double-click the downloaded `.pyw` file to launch the application.
If it does not open, try running it with Python.

4. Start Converting!

1. Enter or paste your LaTeX expression.
2. Click the **Convert** button.
3. View the converted MathCAD expression.
4. Copy the result and use it in MathCAD.

That's it! You're ready to go.

Enjoy using LaTeX to MathCAD Converter!
